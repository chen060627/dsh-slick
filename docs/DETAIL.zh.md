# dsh-slick 详情

## 表格粘贴转 Excel

粘贴一段 **Tab 分隔**、至少 **2 行 × 2 列** 的内容时，插件会在粘贴的瞬间把这段文本转成一个真正的 `.xlsx` 附件，放进草稿，而不是把整块文字塞进输入框。

- 逗号分隔的 CSV **不会**被识别（只有 Tab 分隔）。
- 少于一列或不足两行的内容按普通文本粘贴。
- 生成的是标准 xlsx（ZIP + SpreadsheetML），Excel / Numbers / LibreOffice 都能直接打开。

## 长文本转 txt

当粘贴或输入的纯文本超过阈值（默认 500 字），自动存成 `.txt` 附件。

- 阈值可在 **设置 → 增强工具集** 里改。
- 设为 `0` 关闭这项转存。

## 图片标注

点草稿里的图片缩略图即可打开标注编辑器。

- 工具：画笔、方框、圆圈、直线、箭头、橡皮擦
- 已画的图形可以选中后移动、缩放
- 滚轮缩放画布
- 撤销 / 重做 / 清空
- 保存后得到一张新的图片附件（原图不变）

## Enter 插话发送

智能体运行中按 Enter：

- **开**（默认）：立即插话（steer）
- **关**：排队，等本轮结束再发送

与「设置 → 通用 → 繁忙时的发送行为」是同一项，改一处两边同步。

## 推理等级滑条

把模型菜单里「推理等级」那一行换成一条可拖动的连续滑条（Codex 风格），拖动即改档位。

- 滑条本身由 [`dsh-codex-effort-slider`](https://github.com/Microqian2th/dsh-codex-effort-slider) 提供；本插件负责与模型目录对接、隐藏官方档位列表、以及在滑条模式下隐藏官方团队开关。
- 设置里关掉「推理等级用滑条」后恢复官方原样：点「推理等级」进入官方档位列表。

## 智能体团队协作

模型行右侧有一个 ⚡ 按钮：

- 亮蓝色 = 已开启，点一下关闭
- 灰色 = 已关闭，点一下开启
- 不再弹确认框

开启滑条模式时，官方那一行「启用智能体团队协作」开关会被隐藏，避免两处重复。

## 设置项

| 设置 | 作用 |
| --- | --- |
| 表格粘贴转 Excel | 开关 |
| 长文本转 txt 门槛 | 字数阈值，0 关闭 |
| Enter 插话发送 | 开关（与通用设置联动） |
| 推理等级用滑条 | 开：滑条 + ⚡；关：官方原样 |

「恢复默认」按钮把以上全部重置为插件配置的默认值。
